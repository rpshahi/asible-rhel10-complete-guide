# Contributing to RHCE Ansible Lab Guide

Thanks for helping improve this independent study resource.

## How to suggest improvements

1. Search existing issues before reporting the same problem.
2. Open an issue that identifies the **chapter**, **command or line**, **RHEL and Ansible versions**, and the expected versus actual behavior.
3. For code corrections, include an independently verifiable reference to [Red Hat documentation](https://docs.redhat.com/) or [Ansible documentation](https://docs.ansible.com/).
4. Avoid disclosing real passwords, tokens, SSH private keys, IP addresses from private systems, or proprietary course material.
5. Keep examples beginner-friendly, run `ansible-playbook --syntax-check` where possible, and distinguish tested results from untested examples.

## Pull request checklist

- [ ] Command and YAML syntax reviewed
- [ ] Documentation links and relative paths work
- [ ] Examples use FQCNs for Ansible modules where practical
- [ ] Exam claims are linked to a specific version of the published exam objectives
- [ ] No secrets, third-party paid materials, or screenshots included without permission

> This project is unofficial and not affiliated with or endorsed by Red Hat, Ansible, or Broadcom.
